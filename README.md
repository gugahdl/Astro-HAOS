# Astro-HAOS

Config do Home Assistant OS para detecção local de fenômenos astronômicos
(eclipses, conjunções planetárias, solstícios/equinócios, superluas, chuvas
de meteoros) com notificação quando um evento estiver próximo.

Ver [`docs/fenomenos-astronomicos.md`](docs/fenomenos-astronomicos.md) para
detalhes, instalação e configuração.
